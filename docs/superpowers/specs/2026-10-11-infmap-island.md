# Elaborate Island to Garry's Mod InfMap2

## Goal

Build an external, repeatable pipeline that turns one island generated by the Elaborate erosion/island generator into a large Garry's Mod map running on InfMap2. The generated island should evoke Half-Life 2's Highway 17 coast. Garry's Mod already supplies Half-Life 2 content, so the addon can refer to those materials and models without bundling copies.

## User-approved scope

- Generate one island per export. The sea around it continues through InfMap2's virtual world, with a square ocean surface following the player at sea level.
- Run island generation and heightfield conversion outside Garry's Mod. Garry's Mod only loads and samples the resulting data.
- Read the generated mesh from Elaborate in the browser and export it as a small, versioned JSON interchange file; do not copy Elaborate's source code.
- Convert the mesh to a sampled heightfield and emit an InfMap2 map config plus addon files.
- Use HL2 content for ground and water, with a terrain palette inspired by Highway 17. A drivable coastal road and automatic prop placement are deferred until InfMap2 virtual entity coordinates can be verified in game.
- Make the island extent and heightfield resolution configurable. Keep world extents independent of the original Source BSP bounds through InfMap2.

## Proposed user workflow

1. Generate an island in Elaborate.
2. Run the supplied browser export script on that page and save the JSON.
3. Run the Python builder with the JSON and chosen scale/resolution.
4. Install the generated addon alongside InfMap2, provide/compile its required BSP base, and launch `gm_inf_island`.

## Technical boundaries

- InfMap2's map contract is a BSP base plus `lua/infmap2/<map-name>/main.lua`; the map name must have `inf` as its second underscore-separated word. Its terrain callback returns height for virtual X/Y coordinates.
- InfMap2's documented terrain configuration takes one terrain material. The first version therefore uses one HL2 ground material and provides manual HL2 prop references; it does not promise per-pixel sand/grass/cliff material blending or automatic prop placement.
- The island is finite. Outside the exported field, the callback returns a constant sea-floor height. A separate client-rendered 28,000-unit square follows the player at sea level; its edge may show from high viewpoints or beyond the expected render range. The first version does not promise swimming or water physics.
- The builder caps the generated heightfield at 2,000,000 samples to reject accidental high-memory builds before allocation.
- This environment has no GMod or VBSP/Hammer installation. Deliver source/configuration and a VMF base if feasible, plus clear local compile/install instructions; do not claim an in-game test unless one becomes available.
- Elaborate is a separate web app with an internal graph API. The exporter must validate that API and fail with a useful message if the site changes.

## Out of scope for the first version

- Generating multiple islands while travelling.
- Shipping or repackaging Elaborate, InfMap2, Half-Life 2 materials, models, or other third-party assets.
- A full Highway 17 recreation, authored buildings, or AI/navigation support.
- A drivable coastal road and automatic coastal prop placement.
- An in-game procedural terrain editor.

## Implementation note

The first build supplies the terrain, single HL2 ground material, visual ocean, and manual HL2 cliff-prop references. It does not automatically create a drivable coast road or scatter props; that needs a verified InfMap2 virtual-entity placement pass in GMod.

## Acceptance criteria

- A deterministic fixture export can be processed into a valid terrain dataset and addon config.
- Bad/missing/degenerate input is rejected with an actionable error.
- Sampled heights preserve the input mesh within the chosen grid resolution and configured scale.
- The generated Lua height callback returns interpolated island heights inside bounds and the configured sea-floor value outside bounds.
- The addon has a separate camera-following water surface at sea level, using an HL2 water material.
- Documentation describes the browser export, external build, InfMap2 dependency, BSP requirement, HL2 content usage, and local in-game verification.
